# Limitations

Finite computational reproduction over explicit compactly supported submodels. It directly tests the displayed inequalities, explicit sharpness construction, and upper/lower rate behavior; it is not a proof-assistant formalization of all universal quantifiers.

The NNLS stress test is supplementary; the parent artifact's finite-cover implementation remains the exact proper Yatracos estimator named in the paper. The pair cloud supplies scoped numerical lower-bound evidence and does not replace the paper's all-estimator proof.
