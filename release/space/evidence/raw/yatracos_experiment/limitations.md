# Limitations

This experiment is complete only for its committed finite cover and
contaminant grid. It directly instantiates the paper's named proper Yatracos
estimator and an all-estimator equal-law lower bound, but it is not an
empirical proof of the infinite Gaussian-mixture class minimax theorem.

The quadrature domain is `[-9,9]`; its normalization error is checked below
`1e-12`. The point-mass contaminant grid is adversarial but not exhaustive over
all probability laws. Universal application claims rely on the separate exact
reduction certificate and pinned primary theorems.
